ChatBot de IA

Projeto desenvolvido em Python utilizando Streamlit para criação da interface e a API do Google Gemini através da biblioteca OpenAI.

O objetivo do projeto é criar um chatbot simples capaz de receber mensagens do usuário, enviar o histórico da conversa para um modelo de Inteligência Artificial e exibir a resposta na interface.

Tecnologias utilizadas

Python
Streamlit
OpenAI Python SDK
Google Gemini API
Git/GitHub

Funcionalidades

Interface de chatbot utilizando Streamlit;
Campo para o usuário enviar mensagens;
Exibição das mensagens do usuário;
Exibição das respostas da IA;
Armazenamento do histórico da conversa utilizando st.session_state;
Envio do histórico de mensagens para o modelo Gemini;
Respostas geradas utilizando Inteligência Artificial.
